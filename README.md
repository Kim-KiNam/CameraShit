# CameraShit

삼성 갤럭시 카메라 셔터음을 **PC·케이블·USB 디버깅 없이** 끄는 앱.

## 설치
1. [최신 APK 다운로드](https://github.com/Kim-KiNam/CameraShit/raw/main/releases/CameraShit-v0.3.8.apk)
2. 폰에서 APK를 열어 설치 ("출처를 알 수 없는 앱" 허용 필요)
3. 앱을 열고 화면 안내를 따라 1회 설정 (개발자 옵션 → 무선 디버깅 → 알림창에 6자리 코드 입력)

처음 1회 설정이 끝나면 **Wi-Fi 없이도** 즉시 켜고 끌 수 있고, 재부팅·시스템 업데이트 후 풀려도 자동으로 다시 적용한다.

## 구조 (앱 2개)
- **CameraShit (본 앱)**: 화면, 설정 안내, 알림.
- **CameraShit Helper (도우미, `:helper`)**: 화면 없는 초소형 앱(`targetSdk 22`).
  셔터음 설정 키는 `targetSdk 23+` 앱이 쓰면 시스템이 거부하지만(`WRITE_SECURE_SETTINGS` 가 있어도),
  구형 앱은 `WRITE_SETTINGS` 만으로 직접 쓸 수 있다. 본 앱은 같은 서명 키 앱만 도우미를 호출할 수 있다.

## 원리
셔터음은 삼성 설정 `csc_pref_camera_forced_shuttersound_key` (0 = 끔, 1 = 켬) 로 제어된다.

1. **1회 설정**: 폰 **자기 자신의 무선 디버깅**에 본 앱이 직접 접속(libadb-android)한다. 페어링은 알림창에
   6자리 코드를 입력해서 한 번만 한다.
2. 이 연결(shell 권한)로 도우미를 `pm install --bypass-low-target-sdk-block` 로 설치한다
   (구형 앱은 Android 14+ 에서 이 플래그 없이는 설치가 막혀 있다).
3. 이후 켜기/끄기와 부팅 후 재적용은 **도우미가 직접** 한다. Wi-Fi·adb 불필요.
4. 도우미를 쓸 수 없는 기기에서는 예전 방식(온디바이스 무선 디버깅, Wi-Fi 필요)으로 자동으로 대체한다.

## 시스템 업데이트 후
재부팅 때 값을 확인해서 풀렸으면 자동으로 다시 적용하고, 결과를 알림으로 알려준다.
설정 키가 막혔거나 페어링이 풀린 경우에도 알림으로 알려준다.

## 빌드
Android Studio 에서 열거나 `./gradlew assembleDebug`
(도우미 APK 는 빌드 때 본 앱의 `assets/helper.apk` 로 자동 내장된다. 두 앱은 같은 키로 서명되어야 한다.)

## 한계

- 화면의 "셔터음 끄기가 적용되어 있습니다"는 설정값이 꺼졌다는 뜻이고, 실제 촬영음을 확인한 것은 아니다
